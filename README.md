# Sreeja Dey — Developer Portfolio

Personal portfolio for **Sreeja Dey**, BCA student at Techno India University, Kolkata
and aspiring full-stack developer.

Built with React + Vite + Tailwind CSS v4. Minimal, responsive, static site —
no backend. Deployed on Vercel.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Content

All portfolio content lives in `src/data/portfolio.js` (links, skills, projects,
education). Set `profile.email` to a real public address to enable the mailto
button; set `profile.resumeUrl` to a hosted resume PDF to show the Resume button.
